# Changelog

## 0.1.0

- Internet radio from the radio-browser.info directory, with no account needed.
- Popular, Trending, Top Voted and High Quality lists, and stations by genre, country and spoken language.
- Search every list by station name and narrow it by one or more genres; type in the genre filter to find any tag the directory uses.
- Stations appear in Kalinka's search, most played first.
- Only stations the renderer can play are listed: MP3, AAC and FLAC streams, without HLS.
- Needs Kalinka Player 5.19.0 or newer, which ships plugin SDK 3.22.
